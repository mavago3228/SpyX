# SpyX 🕵️

Videojuego de espías en 3D por ciudades reales: 10 países y 60 misiones.

Operaciones: Colombia, Estados Unidos, Francia, Japón, Reino Unido, Alemania, Brasil, Rusia, Argentina y China.

## Cómo jugar
Abre `index.html` en el navegador, o publícalo con GitHub Pages.

| Tecla | Acción |
|---|---|
| WASD | Moverse |
| Mouse | Cámara |
| Shift | Correr |
| C | Agacharse |
| E | Interactuar, recoger, entrar, dar órdenes a tu pandilla |
| F / Clic | Golpear |
| G | Soltar arma |
| Q | Lanzar moneda |
| T | Hablar con la gente |
| R | Robar taxi |
| M | Mapa |
| P | Pausa |

En celular aparecen botones táctiles.

## Nota
Fuera de Claude, las conversaciones con los NPC usan respuestas automáticas más simples.
El progreso se guarda en el navegador.
